# Noren x402

x402 is HTTP `402 Payment Required` turned into a working payment rail: a
resource answers an unpaid request with a signed price quote, the caller pays
on-chain, and the same request retried with an `X-PAYMENT` header returns the
resource. Noren uses x402 to let agents *pay* for external resources under a
capability grant and a budget.

Settlement, budgeting, audit, and attestation share one accounting path, so a
paid call is a first-class, capability-gated, audited action rather than a side
channel.

## Crates

| Crate | Role |
| --- | --- |
| `noren-x402` | Core types (`PaymentRequirements`, `PaymentExtra`), the `Signer` trait, `EvmSigner` (EIP-3009 `TransferWithAuthorization` over EIP-712), and an in-process EIP-1559 submitter (`EvmRpc`). |
| `noren-x402-signer-evm` | A stdin/stdout sidecar binary: read a `PaymentRequirements` JSON on stdin, get the base64 `X-PAYMENT` header value on stdout. Keeps the funding key out of the daemon process. |

## Money path (Robinhood Chain)

- **Network / asset:** Robinhood Chain (chain id `4663`, CAIP-2 `eip155:4663`), USDG at `0x5fc5360D0400a0Fd4f2af552ADD042D716F1d168`.
- **Authorization:** the paying agent signs an EIP-3009 `TransferWithAuthorization` (EIP-712 domain `Global Dollar`, version `1`). Signing is gasless and never touches an RPC.
- **Settlement:** the authorization is submitted on-chain by a facilitator or by the daemon's own submitter. The funder and the recipient (`payTo`) are always distinct accounts.
- **Fail closed:** if settlement does not succeed, the caller receives a `402` and the resource is never released.

## Paying for resources (outbound)

An agent reaches a paid provider through capability-gated MCP tools. The daemon
signs the x402 payment with the agent's funding key, debits the agent's budget,
writes a settlement receipt, and records the call in the hash-chained audit log.
The agent never holds raw payment plumbing; it calls a tool and gets a result.

The `noren-x402-signer-evm` sidecar is the reusable primitive: feed it the
`PaymentRequirements` from any `402` challenge and it returns the header to
retry with.

```bash
export NOREN_X402_EVM_KEY_HEX=<64-hex funding key>   # never commit
export NOREN_X402_EVM_RPC_URL=https://rpc.mainnet.chain.robinhood.com
export NOREN_X402_EVM_CHAIN_ID=4663
echo "$payment_requirements_json" | noren-x402-signer-evm   # -> base64 X-PAYMENT header
```

A live settlement test lives in
`agent-os/crates/noren-x402/tests/live_rh_usdg_settlement.rs`.

## Gateway

The public gateway runs at **`https://gateway.usenoren.xyz`**. Unpaid requests
to a priced route return an x402 `402` challenge for USDG on Robinhood Chain;
pay and retry to receive the result. A response with status `>= 400` cancels
settlement, so a caller is never charged for an error.
